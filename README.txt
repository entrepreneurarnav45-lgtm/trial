GitHub Pages upload steps
1. Unzip this file. You get index.html and .nojekyll (no folders).
2. In your GitHub repo, upload BOTH files to the ROOT of the repo (not inside a folder).
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Wait 1-2 minutes, then open the Pages link (hard refresh).
The 9 videos, doctor photo, logo and before/after photos are built into index.html, so no other folders are needed.
